# G7-CrisisSync

Group 7 – Engineering Methods for Software Systems Development, ORT Braude College.

CrisisSync is an emergency-management system: events, task dependency trees (DAG), all-or-nothing resource reservation, live status by server push, settlement with an external clearing system, and monthly SLA and utilization reports.

**Stack:** Java, JavaFX desktop client, OCSF over TCP/IP, SQL with ORM.
